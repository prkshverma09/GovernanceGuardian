# Test Data

This directory holds data used for Governance Guardian ingestion and testing.

## Provenance & license

- **Contract documents** in `contracts/`: Sample clauses for compliance testing (data privacy, minors, restricted regions, PII). Generated for this project; not from a licensed dataset. Use only for development and demo.
- **Customer data**: Generated by `scripts/generate_customers.py` (Faker-based synthetic data). Run that script to produce `customers.csv` in this directory before ingesting.

## Layout

| Path | Description |
|------|-------------|
| `contracts/*.txt` | Plain-text sample contracts (NDA, MSA, DPA) with compliance clauses. Ingested by `scripts/ingest_contracts.py`. |
| `contracts/*.pdf` | Optional. Add your own PDFs here, or generate via `python scripts/generate_contracts.py` (requires PyMuPDF). |
| `customers.csv` | Synthetic customer data. Create with `python scripts/generate_customers.py`. |

## Verify contract data (no Elastic required)

From project root:

```bash
python scripts/verify_contract_data.py
```

Expect: 3 `.txt` files, 11 chunks — ready for ingest.

## Ingest order

1. **Contracts**: `python scripts/ingest_contracts.py` — reads all `data/contracts/*.pdf` and `data/contracts/*.txt`.
2. **Customers**: `python scripts/generate_customers.py` then `python scripts/ingest_customers.py`.
